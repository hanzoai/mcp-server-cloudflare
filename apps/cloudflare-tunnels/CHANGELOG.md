# cloudflare-tunnels

## 0.1.0

### Minor Changes

- Initial release of Cloudflare Tunnels MCP Server
- Added support for managing Cloudflare Tunnels via MCP
- Tools included:
  - `tunnels_list` - List all tunnels in account
  - `tunnel_create` - Create new tunnels
  - `tunnel_get` - Get tunnel details
  - `tunnel_config_get` - Get tunnel configuration
  - `tunnel_config_update` - Update tunnel ingress rules and configuration
  - `tunnel_delete` - Delete tunnels
  - `tunnel_token_get` - Get installation tokens
  - `tunnel_connections_list` - List active tunnel connections
